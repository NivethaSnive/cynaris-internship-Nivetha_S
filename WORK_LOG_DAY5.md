- Reviewed Git commit history and branch status.

## Git Commands Practised
- `git checkout -b` — Create and switch to a branch.
- `git add` — Stage changes.
- `git commit` — Save changes as a commit.
- `git rebase -i` — Edit and combine commits.
- `git merge` — Merge branches.
- `git status` — Check the working tree.
- `git log --oneline` — Review commit history.

## Review Checklist
- [ ] Correct branch selected.
- [ ] No secrets or unnecessary files committed.
- [ ] Commit history reviewed.
- [ ] Merge conflict resolved.
